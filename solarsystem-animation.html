Project Details

Behind The Scenes

Project Details

Tools, render settings, and the production pipeline behind this animation.

Tools Used

  • Blender 3.3 (for 3D modeling and animation)
  • Python Scripting (for procedural generation and automation)

Render Information

  • Render Time: Approximately 1 hour and 30 minutes
  • Resolution: 1920x1080 at 24fps
  • Total Frames: 2880 (2 minutes animation)

Key Features

  • Procedurally generated solar system with almost relative sizes
  • Realistic orbital mechanics with almost relative speeds
  • Dynamic camera movements zooming in/out between planets
  • Detailed planetary textures and atmospheric effects
  • Animated informational displays for each planet

Texture Materials

  • High-resolution planetary textures sourced from Solar System Scope's texture library

Animation Sequence

0–8s
Opening Sequence

Camera zooms from the solar system, establishing the scale and style of the animation.

8s / planet
Planetary Tour

Smooth transitions between each planet — Mercury to Pluto — displaying the planet's name.

Final 1 min
Solar System Overview

Camera zooms out to show the complete solar system with all planets orbiting the sun, demonstrating their relative positions and speeds.

Blender Workflow

Method to Make a Planet in Blender

A quick step-by-step walkthrough of how each planet was modeled and textured for this project.

01

Open Blender.

02

Delete the default cube and press Shift + A to create a sphere.

03

Right-click the sphere and select Shade Smooth.

04

Go to solarsystemscope.com/textures and download the textures you want for your planet.

05

In the upper left, click the editor type dropdown and select the Shader Editor.

06

Press Shift + A, select Image Texture, and load the textures you installed.

07

Configure your shader by combining the different texture maps.

08

Switch back to the 3D Viewport to see your finished planet.

Technical Reference — Blender 5.1

Animation Script

The Python script below drives the entire 3D render — camera choreography, orbital timing, depth-of-field per planet, and NLA strip extension across a full 2-minute timeline.

solar_system_camera_fix.py Python · Blender 5.1

9 planet cameras with arc keyframes — arrival, mid, departure

NLA strip extension loops orbit animations across full timeline
